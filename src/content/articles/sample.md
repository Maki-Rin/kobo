この記事では、実際に使用可能な Markdown 記法を確認していきます。

## テキスト装飾のテスト

### 太字のテスト

通常のテキストの中で **太字** を使用すると、プライマリカラーの太字で表示されます。

例：この文章の中で **重要な部分** を強調表示します。

### 斜体のテスト

斜体は _このように_ 表示されます。

例：_斜体テキスト_ を使用して強調します。

### 取り消し線のテスト

取り消し線は ~~このように~~ 表示されます。

例：~~削除された内容~~ を示すことができます。

## リストのテスト

### 箇条書きリスト

- アイテム 1
- アイテム 2
- アイテム 3
  - サブアイテム 1
  - サブアイテム 2

### 番号付きリスト

1. 第一項目
2. 第二項目
3. 第三項目
   1. サブ項目 1
   2. サブ項目 2

## リンクのテスト

外部リンクの例：[KOBO 公式サイト](https://www.usuiyoshito.com)

内部リンクの例：[記事一覧](/articles)

## コードのテスト

### インラインコード

この文章の中で `console.log()` のようにコードを表示できます。

### コードブロック

```javascript
function hello() {
  console.log('Hello, World!');
}

hello();
```

```python
def greet(name):
    print(f"Hello, {name}!")

greet("KOBO")
```
